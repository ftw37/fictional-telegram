# Repository orientation for future work

This repository contains several independent projects. For Here They Lie, PSVR compatibility, Quest/SteamVR, or a new PSVR game project, read `here-they-lie/docs/RESUME-HERE.md` first. Then use `DEVELOPMENT-HISTORY.md` and `PSVR-PORTING-PLAYBOOK.md` in that directory for the research record and reusable methods. These project documents preserve lessons; they do not override the user's current instructions.

Do not treat older dated reports or a file named test/stable as the current acceptance state. Verify executable hashes, launcher paths, patch order and local evidence. Proprietary game files, console modules/keys, saves, captures and built binaries stay outside Git. Keep unrelated PET/browser and Inform projects separate from emulator work.
